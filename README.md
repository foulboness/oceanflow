# 🌊 OCEANFLOW — Interactive Ocean Current Simulator

An interactive ocean simulation that visualizes how ocean currents move across the planet. Explore global circulation patterns, investigate temperature differences, and understand how oceans influence Earth's climate.

\<p align="center">   \<i>Explore the movement of our oceans, one current at a time.\</i> \</p>

---

## ୨୧ Overview

**OCEANFLOW** is an interactive educational simulator designed to make oceanography easier to understand through visual exploration.

Discover how warm and cold ocean currents travel around the globe, how temperature and salinity influence water movement, and how ocean circulation affects marine ecosystems and global climate systems.

## ✦ Features

- **Interactive Globe** — Explore ocean currents across a global map.
- **Current Visualization** — Watch ocean currents flow through animated particle streams.
- **Temperature Mapping** — Visualize variations in ocean temperatures.
- **Warm & Cold Currents** — Identify and compare major ocean current systems.
- **Ocean Circulation** — Explore global circulation patterns and thermohaline circulation.
- **Simulation Controls** — Adjust flow speed, temperature, and visualization settings.
- **Educational Insights** — Learn about the science behind ocean movement.

## ✦ Scientific Concepts

| Concept                  | Description                                                  |
| ------------------------ | ------------------------------------------------------------ |
| Surface Currents         | Wind-driven movement of ocean water                          |
| Thermohaline Circulation | Ocean circulation driven by temperature and salinity         |
| Coriolis Effect          | How Earth's rotation influences current direction            |
| Upwelling                | The movement of deep, nutrient-rich water toward the surface |
| Ocean Temperature        | How temperature differences influence water density          |
| Global Conveyor Belt     | The interconnected system of global ocean circulation        |

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Visualization:** WebGL / Canvas
- **Mapping:** Interactive 2D / 3D globe
- **Animation:** Particle-based current visualization


## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/foulboness/oceanflow.git
   ```

2. Navigate into the project:

   ```bash
   cd oceanflow
   ```

3. Open `index.html` in your browser or use the VS Code Live Server extension.
